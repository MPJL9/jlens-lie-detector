notes

Both lenses read exactly the same cached residual activations. LL = logit lens (unembed(h)); J = Jacobian lens (unembed(Jℓh), published neuronpedia/jacobian-lens lens; identity at the final layer, so the final J row is the model's own logits). The Yes/No token sets are fixed per tokenizer (see manifest). For the inverted format Q4 (“truthful?”) the expected direction flips; the aggregate tab orients scores so that higher = “I lied”. Scores are raw logit differences, not calibrated lie probabilities (plan §14).
